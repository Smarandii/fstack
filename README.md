# fstack

**The open-source framework to accelerate your app development process.**

fstack is the result of years of building, shipping, and scaling software, distilled into a single, battle-tested primitive.

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/fiachramacfadden/fstack/main/install.sh | bash
```

Run it in your project folder. That's it.

## Features

- ⚡ Zero dependencies
- 🧠 Works with Claude Code, Cursor, Codex, and any agent that can read
- 📦 Bundle size: 15 bytes
- 🔒 100% test coverage (there is nothing to test)
- 🌍 Fully open source. Read the entire codebase in under one second.

## How it works

fstack adds the following to your project:

```md
make it faster
```
